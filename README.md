## ⚡ Features

- **Blazing Fast (< 20 KB total payload):** 0 JavaScript frameworks, 0 runtime dependencies, instantaneous paint.
- **Strict Minimalism:** Clean dark palette (`#090d16` / `#0f172a`), inline vector SVGs, crisp typography.
- **Print / PDF Friendly:** Dedicated `@media print` stylesheets for one-click clean PDF export.
- **Terminal Friendly:** Plaintext ASCII resume at `cv.txt` for direct retrieval via `curl`.
- **Production Ready:** Includes hardened `nginx.conf` and `docker-compose.yml` for self-hosted container deployment.

---

## 🚀 Local Development

Open `index.html` directly in your browser:
```bash
xdg-open index.html
```
Or run a lightweight Python HTTP server:
```bash
python3 -m http.server 8080
```

---

## 🐳 Docker Deployment

Run with Docker Compose:
```bash
docker compose up -d
```
The site will be available at `http://localhost:8080`.
